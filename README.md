# BORB Public Documentation

This folder contains the public Orion Rigel and BORB documentation set intended for non-admin users.

Use these docs for:
- dashboard navigation
- collections, leads, and scenarios workflow guidance
- simulation and optimization basics
- KPI explanations that are safe to share publicly
- upload, integration, and support references

This public set should avoid:
- internal architecture details
- admin-only workflows
- observability internals
- privileged operational procedures
- sensitive billing, impersonation, or security implementation details

Recommended structure:
- `dashboard/README.md`
- `collections-scenarios/README.md`
- `simulations/README.md`
- `metrics/README.md`
- `optimization/README.md`
- `account-access/README.md`
- `uploads/README.md`
- `integrations/README.md`
- `logging/README.md`
