# Account and Access

## At A Glance

Public guidance for signing in, recovering account access, understanding subscription-related access, and knowing when to contact support.

## How To Use This README

- Use this README for account and access questions that can be answered without admin-only procedures.
- Keep instructions focused on visible user actions and support-ready context.
- Send internal role, impersonation, or security-sensitive details to internal documentation instead.

User-facing guidance for signing in, managing account basics, and understanding access limits in Orion Rigel.

## What Users Can Do

- Sign in to an existing account.
- Reset a password or recover access through supported account flows.
- Update basic profile information where available.
- Review subscription-related access in the product.
- Contact support when account or access issues cannot be resolved directly.

## Common Questions To Cover

- Where do I sign in?
- What should I do if I cannot access my account?
- Why do I see a subscription or feature-limit message?
- Where should account-related support requests go?

## Public-Safe Guidance

Use plain language and focus on user actions. Include the information a user should provide to support, such as account email, approximate time of issue, visible error message, and the page where the issue occurred.

## Do Not Include

- Internal role escalation procedures.
- Impersonation workflows.
- Private admin troubleshooting steps.
- Security-sensitive implementation details.

## Maintenance Notes

- Update this README when public account flows, profile settings, or subscription-access language changes.
- Do not add private admin troubleshooting, impersonation steps, or security implementation details.
