# Dashboard Basics

The Orion Rigel dashboard is the main operating surface for navigating collections, leads, scenarios, and reporting tools.

## What users should do here
- review current collections and activity
- navigate to leads and scenarios
- access simulations and comparisons
- open support resources when guidance is needed

## What to document publicly
- page navigation
- where primary actions live
- how to interpret top-level summaries
- common first steps for new users
