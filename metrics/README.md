# Metrics and KPI Basics

## ✨ At A Glance

Public explanation framework for financial and operating KPIs such as IRR, cap rate, cash-on-cash return, DSCR, NOI, occupancy, and break-even concepts.

## 🎨 Reader Promise

> Users should get plain-English metric meaning and comparison guidance without being dragged into internal formula code.

## 🧭 How To Use This README

- Use this README as the standard for explaining what metrics mean and how users should compare them.
- Keep interpretation framed as decision support rather than investment advice or guarantees.
- Avoid internal formulas and implementation details in public metric explanations.

Public guidance for the major financial and operating metrics users see throughout Orion Rigel.

## 📊 Public-Safe KPI Topics

- IRR.
- Cap rate.
- Cash-on-cash return.
- DSCR.
- NOI.
- Occupancy and break-even concepts.

## 🧾 What Each Metric Guide Should Explain

- What the metric means.
- Why it matters.
- Which assumptions can affect it.
- How to compare it across scenarios.
- When users should review supporting assumptions before acting.

## 🧠 Interpretation Guidance

Metrics should be treated as decision-support outputs. Users should compare them across consistent assumptions, review source inputs, and apply underwriting judgment before making investment decisions.

## 🔒 Public-Safe Boundary

Do not include internal formulas, validation internals, private benchmark data, or implementation-specific calculation code in public docs.

## 🛠️ Maintenance Notes

- Update this README when public metric names, interpretation guidance, or KPI coverage changes.
- Keep internal formula details, benchmark data, and validation mechanics in internal docs.
