# Debt Yield

Debt yield measures annual NOI relative to the outstanding or proposed loan amount. It is independent of interest rate, amortization, and property valuation.

## Formula

```text
Debt Yield = Annual NOI / Loan Amount
```

## Inputs and conventions

- Use NOI before debt service and financing costs.
- Identify whether the denominator is original principal, proposed proceeds, or current balance.
- Use a consistent trailing, underwritten, or stabilized NOI definition.

## Interpretation

Debt yield estimates the lender's unlevered income return on its loan basis. Higher debt yield generally indicates a larger NOI cushion relative to principal, but it does not describe payment affordability under the actual loan terms.

## Worked example

With NOI of `$500,000` and a loan of `$5,000,000`:

```text
$500,000 / $5,000,000 = 10.0%
```

## Limitations and checks

- Debt yield ignores interest rate, amortization, maturity, and collateral value.
- Aggressive NOI assumptions can overstate the metric.
- Review the trailing-to-underwritten NOI bridge, DSCR, LTV, property condition, and refinancing risk.
