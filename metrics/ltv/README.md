# Loan-to-Value Ratio (LTV)

LTV measures the loan balance relative to a stated property value.

## Formula

```text
LTV = Loan Amount / Property Value
```

## Inputs and conventions

- Use original loan amount for origination LTV and current balance for current LTV.
- Identify whether value is purchase price, appraised value, or current estimated market value.
- For multiple liens, distinguish senior LTV from combined LTV.
- Use loan and value figures from the same effective date when possible.

## Interpretation

Higher LTV means more leverage and less collateral-value cushion. Lower LTV generally reduces lender exposure but requires more equity. LTV is not an income-coverage metric.

## Worked example

For a `$4,500,000` loan on a property valued at `$6,000,000`:

```text
$4,500,000 / $6,000,000 = 75.0%
```

## Limitations and checks

- The ratio changes immediately when the valuation changes, even if the loan does not.
- An appraisal can become stale or depend on assumptions that differ from underwriting.
- Review DSCR, debt yield, amortization, maturity, subordinate debt, and value sensitivity alongside LTV.
