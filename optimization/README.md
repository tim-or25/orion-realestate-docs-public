# Optimization How-To

## ✨ At A Glance

Public guide for optimization workflows that help users explore alternative assumptions and review scenario tradeoffs.

## 🎨 Reader Promise

> This page should make optimization feel like guided exploration: useful suggestions, visible tradeoffs, and no false sense of automatic certainty.

## 🧭 How To Use This README

- Use this README when documenting how users start, review, compare, and save optimized scenario outputs.
- Keep tradeoff review and underwriting judgment visible in the guidance.
- Avoid presenting optimization as an automatic final decision.

Optimization features help users explore alternative assumptions and identify stronger scenario configurations.

## ✅ What Users Can Do

- Start an optimization run from an eligible scenario.
- Select the objective or category they want to explore.
- Review optimized outputs and changed assumptions.
- Compare the optimized case against the original scenario.
- Save or continue reviewing the result when appropriate.

## 🌐 Public Guidance

- Explain how to start a run.
- Show how to compare optimized outputs.
- Encourage review of tradeoffs instead of blindly accepting suggestions.
- Remind users to validate scenario changes before relying on them.

## ⚠️ Important Note

Optimization suggestions support judgment. They do not replace underwriting review.

## 🛠️ Maintenance Notes

- Update this README when optimization entry points, public categories, comparison behavior, or save flow changes.
- Do not include solver internals, provider prompts, private scoring logic, or admin-only diagnostics.
